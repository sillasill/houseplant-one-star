One line, under 280 characters: a houseplant's 1-star review of its human owner, with a grievance and a reason for the single star — judged head to head by an AI judge.

Entry for the make.fun bounty

## Run it

```sh

```

Writes the review to `/output/entry.txt`. Deterministic, standard library
only, no network, no API keys.
